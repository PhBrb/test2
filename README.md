# Tetris Game

A classic Tetris game that can be played directly in your browser. Built with pure HTML5, CSS, and JavaScript.

## Play the Game

Once deployed to GitHub Pages, you can play at: https://PhBrb.github.io/test2/

## How to Play

### Controls
- **Left Arrow**: Move piece left
- **Right Arrow**: Move piece right
- **Down Arrow**: Move piece down faster
- **Up Arrow**: Rotate piece
- **Space**: Hard drop (instantly drop piece)
- **P**: Pause game

### Game Mechanics
- Clear lines by filling rows completely
- Score increases with each line cleared
- Level increases every 10 lines cleared
- Game speeds up as you level up
- Game over when pieces stack to the top

## Features

- Classic Tetris gameplay
- Score tracking
- Level progression
- Next piece preview
- Responsive design
- Keyboard controls

## Setup for GitHub Pages

1. Go to your repository on GitHub
2. Click **Settings** > **Pages**
3. Under "Source", select **main** branch
4. Click **Save**
5. Your game will be live at `https://PhBrb.github.io/test2/`

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling for the game
- `game.js` - Game logic and controls
